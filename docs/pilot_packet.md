## C. 去識別化守則（全隊遵守，印在問卷背面）

做：
□ 問卷只寫編號（如 1219-03），不記姓名、電話、地址
□ 錄音轉文字後 24 小時內刪原檔，檔名用編號（`field_1219-03.txt`）
□ 對外分享只講統計（如：8 成長者接過可疑電話）
□ 紙本當日拍照傳隊長，正本交回學校保管箱

毋通做：
✕ 記姓名、電話、地址、身分證字號
✕ 拍證件、存摺、門牌、藥袋個資面
✕ 把原始錄音、照片傳上雲端或群組
✕ 未經同意拍攝長者正臉（必須拍時戴口罩或只拍背面／手部）

## E. 拍照 checklist（離開據點前勾完才能走）

- [ ] 已取得里長口頭同意＋簽署 D 節意向書
- [ ] 每張拍攝前先問：「這張可以拍嗎？會放到比賽簡報。」點頭才按快門
- [ ] 長者臉部不上鏡為原則；必須拍時戴口罩或只拍背面／手部操作畫面
- [ ] 必拍 3 張：①據點外觀＋布條 ②大字報特寫（紅字清楚）③隊員訪談側拍（不露臉）
- [ ] 當日照片交隊長統一保管，手機相簿刪除原圖
- [ ] 紙本問卷已拍照備份，正本裝袋帶回

## F. 兩週達標檢核（隊長用）

- [ ] 長者問卷 ≥5 份（A 節）
- [ ] 模擬電話紀錄 ≥10 通或「5 位長者各 2 通」（B 節）
- [ ] 里長意向書 ≥1 份（D 節）
- [ ] 據點照片 ≥3 張（E 節）
- [ ] 全數去識別化複核通過（C 節）
