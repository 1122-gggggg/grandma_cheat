# 備份影片逐秒腳本（2 分鐘版）— 阿嬤的台語反詐守門員

> 用途：決賽現場太吵／麥克風壞／評審聽不清時，直接切這支片，全程 120 秒講完。
> 規格：全程 1080p（1920×1080）、中文字幕燒錄、手機直錄終端機畫面即可開拍。
> 拍攝設備：一支手機＋一台筆電＋安靜房間。不需麥克風、不需網路、不需攝影師。
> 播放檔案：輸出 `backup_120s_1080p.mp4`，另存 USB 隨身碟＋筆電桌面各一份，檔名固定。

## 0. 開拍前檢查清單（10 分鐘搞定）

- [ ] 筆電 Wi-Fi 關掉（證明離線可跑，片尾會特寫工作列無網路圖示）。
- [ ] 終端機字體調到最大（GNOME Terminal：`Ctrl + +` 放到 28pt 以上；VS Code 終端機同理）。
- [ ] 終端機視窗最大化，背景黑、字體白，執行前先 `clear`。
- [ ] 手機架在筆電正前方約 40 公分，橫拍 16:9，畫面只框住終端機＋雙手，確認紅字大字報在手機裡清晰可讀。
- [ ] 預跑一次確認三段燈號正常：
  - `uv run python -m antiscam.demo.runner --mode fraud`（應出現黃→紅）
  - `uv run python -m antiscam.demo.runner --mode normal`（應全程綠）
- [ ] 房間安靜，冷氣出風口避開手機收音孔。現場翻車時此片直接全螢幕播放，不需現場收音。

## 3. 後製規格（手機 App 即可，不需 Premiere）

- 解析度：1080p（1920×1080 橫式），幀率 30fps，輸出 H.264 mp4，檔名 `backup_120s_1080p.mp4`。
- 字幕：全程燒錄繁中字幕（用上述「燒錄字幕」欄逐字貼），字體思源黑體／Noto Sans TC Bold，字級佔畫面高度 1/12 以上，紅燈段關鍵詞用紅字。
- 音訊：旁白一支手機在棉被裡錄乾音即可，詐騙段加電話雜訊（Audacity「Telephone」預設或免後製直接壓嗓唸）。全片音量一致，不爆音。
- 剪接點：只在四段交界處硬切（15／70／100 秒），段內不剪，證明 demo 無造假。紅綠對比處可加一次 0.5 秒並排（左紅右綠），其餘不加特效。
- 輸出檢查：播一次確認 120 秒內結束、字幕無錯字、終端機紅字清晰、Wi-Fi 打叉有拍到。

## 4. 翻車備案：現場太吵切此片（30 秒內接上）

- 觸發條件：現場音響嘯叫、麥克風無聲、後排聽不清台語，或操作手連打錯兩次指令，隊長直接說備案台詞。
- 備案台詞（一句話，全隊背起來）：「現場較吵，我們直接播 2 分鐘備份片，內容跟剛才 demo 完全共款！」（操作手同時按 `Win + D` 切桌面，雙擊 `backup_120s_1080p.mp4` 全螢幕播放。）
- 播放時全隊安靜，隊長在紅燈處（約 1 分鐘）指螢幕補一句：「這就是紅燈大字報！」綠燈處補一句：「孫子打來是綠燈，不會誤擋！」其餘不說話，讓片自己講完。
- 播完收尾（一句話）：「片裡這三段，現場斷網一樣跑得出來，評審隨時可以考我們打字互動！」直接進提問，不重播 demo。
