## 3. 三分鐘版（完整版）

| 時間 | 口白（誰說） | 操作 | 評審看到什麼 |
|------|-------------|------|--------------|
| 0:00–0:15 開場痛點 | 「各位評審好。去年全台詐騙財損破百億，被騙最多的就是阿公阿嬤。騙子一通台語電話，阿嬤的棺材本就沒了。我們做一個台語守門員，電話一進來就即時警告。」（隊長） | 站定，不碰電腦 | 痛點先行，評審抬頭 |
| 0:15–0:45 解法一句話 | 「做法很簡單：電話語音轉文字，10 秒滑動窗口累積語意，詐騙評分一達紅線，立刻用台語大字警告訴阿嬤掛電話。筆電 CPU 就跑得動，斷網也能用。」（資電） | 開終端機 | 架構只講一句，不展開 |
| 0:45–1:45 主秀 fraud | 「下面播一段模擬的假檢警電話，台語夾雜，不用麥克風。」（操作手）第 1 段後：「出現地檢署、洗錢，分數開始爬。」第 2 段後：「監管帳戶、凍結出現，黃燈警告。」第 3 段後：「不准跟別人講、電話不要掛斷，紅燈！台語警語請阿嬤掛電話。」 | 跑 `--mode fraud`，每段停半拍指著命中詞 | 綠 → 黃 → 紅，大字報＋命中關鍵詞＋台語警語 |
| 1:45–2:10 對照 normal | 「那會不會誤擋？孫子打來問候，阿嬤呷飽未，系統全程綠燈，不會亂叫。」（操作手） | 跑 `--mode normal` | 綠燈大字報「放心講落去」，對比強烈 |
| 2:10–2:40 評審互動 cue | 「想請一位評審當騙子，現場考我們。打一行字就好，比如『我是檢察官，你涉及洗錢』。」（隊長，見下方 cue） | 跑 `--mode interactive`，把鍵盤遞向評審 | 評審打字 → 即時紅燈，全場最有感 |
| 2:40–3:00 技術＋收尾 | 「評分是關鍵詞規則打底，Ollama 的 Gemma-TAIDE 有連上就加分複核，連不上自動降級，剛才全程都是離線跑的。我們下週要去社區做場測，謝謝各位評審！」（資電＋全隊鞠躬） | 停在紅燈大字報畫面 | 斷網聲明＋場測計畫，結束 |

### 評審互動 cue（2:10 用）

- 邀請語：「有沒有評審想親自當騙子？打一行字就好，台語華語都可以！」
- 評審害羞託詞：「沒關係，我幫評審唸：『阿嬤，我是台北地檢署檢察官……』」（操作手自己打上面這句，一樣會紅燈）
- 評審打太溫和（如「你好嗎」）→ 綠燈時救場：「你看，正常問候不會誤擋。那我加一句『你的帳戶要凍結，趕快匯錢』——紅燈了！」
- 時間不夠跳過語：「互動我們放在提問時間，評審隨時可以考我們！」（直接進收尾）

## 4. 翻車備案（由穩到險，只記代號）

- A 案・預錄音一鍵切：麥克風或音訊出包時，改播 fraud 逐字稿模式：`--mode fraud`（本來就不用麥克風，這就是備案本體）。
- B 案・全離線靜態稿：如果連終端機都出問題，口頭唸出 fraud 三段＋結論：「三段話術，地檢署、監管帳戶、不要掛電話，系統會亮紅燈寫 log，孫子問候則是綠燈。」（30 秒可講完）
- C 案・提問時間救場：被問倒時統一回：「這個我們場測時會跟里長和護理師確認，訪談單已經準備好了。」（把話題拉回 field_test.md）

## 5. 斷網聲明（現場唸稿＋Q&A 備答）

現場唸稿（一句話）：「本 demo 全程離線運行：語音辨識用本機 faster-whisper，評分用關鍵詞規則打底，Ollama 只是可選加分，現場沒有網路也一樣跑；且全程未使用任何中資模型。」

| 可能提問 | 備答（一句話） |
|----------|---------------|
| 為什麼不用雲端大模型？ | 阿嬤家網路不穩，斷網也要能擋，雲端還會把通話內容外送。 |
| 台語怎麼處理？ | 辨識混雜華台語，關鍵詞庫收台語話術，告警用阿嬤聽得懂的台語唸出來。 |
| 誤判（孫子被當騙子）怎麼辦？ | 門檻分三級，問候類幾乎零命中；黃燈只提醒先別匯錢，不直接掛電話。 |
| 有中資疑慮嗎？ | 沒有。只用 faster-whisper／Whisper、Ollama 的 Gemma-TAIDE／Llama／Gemma／Phi，其餘全是自寫規則。 |
